Project at a Glance

EduGuard-AI is an explainable and uncertainty-aware early academic risk predictor. Using OULAD learning activity from course days 0–27 plus known background features, it estimates the eventual Fail/Withdrawn risk. Logistic Regression and Random Forest are compared, Random Forest is chosen on validation F1, and SHAP, conformal prediction, and rule-based support suggestions are presented through Streamlit.

30-Second Presentation

My project EduGuard-AI identifies possible academic risk early using the first 28 days of learning activity. It compares Logistic Regression and Random Forest and selects the model by validation F1-score. It also explains individual predictions using SHAP, quantifies uncertainty using conformal prediction, and displays results in a Streamlit dashboard. The aim is to support, not replace, academic advisers.

2–3 Minute Presentation

The educational problem is that academic difficulties may be recognized too late. My system uses the Open University Learning Analytics Dataset, with early VLE clicks, active days, assessment submissions and scores, previous attempts, studied credits, and course identifiers. The records are cleaned and restricted to the first 28 course days. Students are separated into train, validation, calibration, and test partitions, approximately 50%, 20%, 15%, and 15%. I fit Logistic Regression and Random Forest, choosing the final model using validation F1-score. Random Forest was selected. It generates risk probabilities for eventual Fail/Withdrawn outcomes. SHAP shows local feature contributions, while conformal prediction returns a calibrated set of plausible labels and can flag ambiguous cases. The Streamlit interface provides model evaluation, individual risk prediction, local explanations, batch CSV processing, and rules for academic support. This is a research prototype and does not autonomously decide student outcomes.

Likely Viva Questions & Model Answers

Q1. What is the main objective?

Answer: Identify possible academic risk early, explain model predictions, quantify uncertainty, and suggest support for human review.

Q2. Why is this an Advanced AI project?

Answer: It integrates predictive ML, local explainability, separate conformal calibration, validation-based model selection, and an interactive decision-support workflow.

Q3. Why was Random Forest selected?

Answer: It was chosen using validation F1-score. On the reported test partition it achieved F1 = 0.7342 and ROC-AUC = 0.8261.

Q4. Why did Logistic Regression have slightly higher accuracy?

Answer: Accuracy and F1 measure different aspects of classification. The 0.06 percentage-point accuracy difference is very small and does not imply universal superiority.

Q5. What is the difference between SHAP and conformal prediction?

Answer: SHAP explains a model prediction; conformal prediction provides a calibrated set of plausible labels.

Q6. Why only the first 28 days?

Answer: To frame an early-warning task and avoid using later course activities not available at the intended prediction time.

Q7. Why use four separate dataset partitions?

Answer: Training fits models, validation selects the model, calibration determines the conformal threshold, and testing provides final evaluation.

Q8. What does student-disjoint mean?

Answer: The same student ID cannot occur across different data partitions, reducing repeated-student leakage.

Q9. What does 90.45% coverage mean?

Answer: For the evaluated test records, the true label was included in the Random Forest conformal set 90.45% of the time; this does not guarantee every student's prediction.

Q10. What does average set size 1.3899 mean?

Answer: Random Forest returned about 1.3899 candidate labels per test record on average. A smaller set is more informative when coverage remains adequate.

Q11. What happens for an uncertain case?

Answer: When both labels or no labels are in the conformal set, the app flags uncertainty and recommends human review.

Q12. How are support recommendations produced?

Answer: Using transparent, predefined rules based on activity, submissions, scores, and earlier attempts; they are not learned or causally validated policies.

Q13. What is the main limitation?

Answer: A single observational dataset and one reported split cannot establish fairness, cross-institution generalization, prospective validity, or intervention effectiveness.

Q14. Can this replace teachers?

Answer: No. It is a decision-support prototype that requires qualified human interpretation.

Q15. What is the future work?

Answer: Validate across course cohorts and institutions, assess fairness, track drift, try richer time-series features, and test support interventions.

Q16. Is 74.84% accuracy sufficient for deployment?

Answer: Not by itself. More external, temporal, subgroup, calibration, and operational evaluation is required.

Q17. Why could F1 improve while accuracy falls?

Answer: A classifier can improve positive-class precision/recall while making slightly more total errors.

Q18. Why not start with deep learning?

Answer: The inputs are a small tabular feature set. Logistic Regression and Random Forest provide practical, interpretable baselines.

Q19. Does SHAP show causation?

Answer: No. It describes attributions within the trained model, not the effect of changing a student's behavior.

Q20. Is conformal coverage the same as accuracy?

Answer: No. Coverage measures whether the true class is included in a set; accuracy measures correctness of a single predicted class.

Five Quick Check Questions

Which model was selected? Random Forest.

What does SHAP do? Explains model predictions through local feature contributions.

Why calibration data? Estimate the conformal cutoff.

What is Random Forest's test ROC-AUC? 0.8261.

What to do for uncertain sets? Refer to a human educator or adviser.

Closing Statement for the Viva

EduGuard-AI goes beyond a single predicted label by providing feature-level explanations and calibrated uncertainty sets. It integrates several advanced AI concepts into a practical academic early-warning research prototype. It supports human decision-making but does not establish causal effects or justify automated student interventions.
